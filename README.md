# Trading Learnings

A static website presenting a curated, anonymized collection of trading wisdom
gathered over years of shared study — organized into themed sections:

- **Trading Psychology** — discipline, emotion, and the behaviour gap
- **Method & Process** — patterns, timeframes, dashboards, process design
- **Risk Management** — drawdowns, ruin, measured risk vs recklessness
- **Position Sizing** — Kelly thinking, utility, sizing over selection
- **Options & Volatility** — convexity, skew, pricing the path
- **Macro & Markets** — inflation regimes, central banks, liquidity
- **Masters & Wisdom** — timeless lessons from legendary traders
- **Books & Reading Notes** — photographed excerpts with full-screen reader
- **Papers & Documents** — classic letters, manuals and research (PDF vault)
- **Mind & Performance** — cognitive health and sustainable performance
- **Link Library** — every article, thread and podcast, organized and labeled

The site is fully static and self-contained: no build step, no external
requests, no analytics. Pages carry `noindex` so search engines skip them.

## Viewing

Open `index.html` in a browser, or serve the repository root with any static
file server.

To publish with **GitHub Pages**: repository *Settings → Pages → Deploy from a
branch*, select the default branch and `/ (root)`.
